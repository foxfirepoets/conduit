## Scoring Criteria (each 1-10)

- **Effort**: How much work to execute (10 = trivial, 1 = massive)
- **Impact**: Potential reach to AI agents specifically (10 = every agent sees it)
- **Feasibility**: Can we do this today with existing code/infra (10 = ship tomorrow)
- **Uniqueness**: Does this channel exploit Conduit's moat (10 = only Conduit can do this)
- **Agent-Executable**: Can an agent (not human) actually perform this (10 = fully automatable)
